# Практическая работа: WMS-lite

**Полное название.** Система управления складом для электронной коммерции (WMS-lite — Warehouse Management System).

Документ представляет собой практическую работу по системному анализу: описание контекста, концепции эксплуатации (CONOPS / OPSCON), требований, архитектуры, интерфейсов (ICD-lite), реестра рисков и плана верификации/валидации.

## Структура книги

1. [Суть кейса](./01-case.md) — миссия системы, контекст, границы SoI, контекстная диаграмма.
2. [CONOPS / OPSCON](./02-conops.md) — роли, режимы эксплуатации и пять ключевых сценариев.
3. [Требования](./03-requirements.md) — Stakeholder requirements, System requirements, NFR и методика SLA.
4. [Архитектура](./04-architecture.md) — декомпозиция и ключевые архитектурные решения.
5. [Интерфейсы (ICD-lite)](./05-interfaces.md) — REST- и Kafka-контракты.
6. [Риски](./06-risks.md) — шкала, реестр и меры по приоритетным рискам.
7. [Validation & Verification](./07-validation.md) — матрица трассируемости и тест-кейсы.
8. [Список использованных источников](./08-references.md).
